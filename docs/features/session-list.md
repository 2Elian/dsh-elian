# session-list

列出当前对话的全部提问，点击跳转到发送该消息的位置。

安装见 [安装指南](../install.md)。包名：`@2elian/dsh-client-ui-session-list`。

## 功能特性

- **逐轮列出提问**：每条显示 `#轮次` 徽章、提问正文（最多 3 行）、该轮回答的摘要。
- **点击跳转**：落到那条提问自己的行上；不在已加载范围时自动往回翻历史页。
- **筛选提问**：顶部输入框按提问正文或回答正文过滤。
- **键盘操作**：`↑` `↓` 切换，`Enter` 跳转，`Esc` 关闭。
- **打开即定位最新**：面板打开时自动滚到最后一轮。
- **未回答可见**：本轮还没有回答时标注「（未回答）」。
- **不依赖宿主投射**：即使装配里没挂 `dsh-session-turn-outline`，也能从事件现折出完整轮次表。

## 用法

1. 打开一个会话，点对话头部右侧的**列表**按钮。
2. 浏览或筛选提问。
3. 点击其中一条跳转。

## 入口位置

| 部件 | 座位 |
| --- | --- |
| 列表按钮 | `conversation.session.header.utilities` |
| 提问列表面板 | `conversation.input.overlay` |

## 实现要点

- 轮次表由 `buildTurnItems()` 从浏览器的事件窗口现折：遇到 `turn/start` 开一轮；该轮内**第一条人类** `user/message` 作为提问正文（`source.kind === 'user'`，注入的技能正文、工作区规则、cron 通知不算提问）；最后一条 assistant 文本作为回答（对齐 `ui-chat` 轨道 rail 的 `findLast` 语义）。
- 每轮记住 `turn/start` 的 `seq`，那是回溯翻页的游标；以及 `anchorKeys`，那是滚过去要用的行锚点（优先提问自己的行，否则该轮的 tail 行）。
- 跳转复用与 `session-delta-search` 同一套落点逻辑。

## 与 DSH 自带轮次轨道的关系

DSH 的正文右侧已经有一条固定间距的刻度轨道（`ui-chat` 的 `TurnNavigator`），但它只画刻度、悬停才出预览，且落点逻辑是组件内部的、插件无法调用。这个面板提供的是**可读、可筛选、可键盘操作**的列表版本——提问很多时能直接看到每一轮写了什么。

两者互不依赖。

## 已知限制

- **未加载的历史不会出现在列表里**。提问正文来自已加载的事件窗口；面板底部会提示还有未加载的部分。这一点比 `session-delta-search` 更明显，因为搜索可以主动翻页，而列表只反映当前窗口。
- 「提问」只认 `source.kind === 'user'` 的消息。
- 与 `session-delta-search` 共用同一套 DOM 锚点契约，上游改动会同时影响两者。
